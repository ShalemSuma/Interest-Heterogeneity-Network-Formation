# Raw Data

This directory should contain the full datasets used in the analysis.
These files are not included in the repository due to their size.

## Required Files

| File | Size | Description | Source |
|------|------|-------------|--------|
| `YoutubeNodes.csv` | ~300 KB | YouTube channel nodes with modularity classes | Exported from Gephi network analysis |
| `YoutubeEdges.csv` | ~36 MB | YouTube subscription edges | Exported from Gephi |
| `processed_network_data.json` | ~86 MB | Pre-processed network data for visualisation | Generated by network processing pipeline |
| `complete_data_with_centrality_processed.csv` | ~3 MB | Channels with computed centrality metrics | Generated by `06_network_analysis.ipynb` |
| `video_data/` | ~5,000 files | Per-channel video metadata CSVs | Collected via YouTube Data API v3 |

## How to Obtain the Data

1. **YouTube channel and edge data**: Collected from YouTube's public subscription
   network using the YouTube Data API v3 and exported via Gephi.
2. **Video data**: Run `04_youtube_data_collection.ipynb` with valid YouTube API
   credentials (see `.env.example`).
3. **Processed data**: Run notebooks 05-06 in order to generate centrality metrics
   and interest vectors.

## Sample Data

Small sample files are provided in `../sample/` for testing the code without
the full datasets.
